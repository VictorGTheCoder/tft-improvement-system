Post-game learning, not live coaching

Turn TFT decisions into deliberate practice.

TFT Improvement System helps players capture uncertain decisions, review them after the match, identify recurring mistakes and create spaced-repetition drills. The application is local-first and does not prescribe actions during active gameplay.

User flow

Play, capture, review, retest.

The product is built around long-term improvement. It does not attempt to solve the live game state or replace player judgment.

1

Set one training objective

The player selects a measurable skill for a short block of games, such as economy discipline or scouting before a major commitment.

2

Capture the local match context

The current prototype supports manual capture. The planned Overwolf integration passively records supported local-player data and stores it locally.

3

Review after the match

The player compares the information available at the time, the alternatives considered, the prediction, the action and the observed outcome.

4

Extract a conditional principle

The review produces a rule with conditions and exceptions instead of a generic statement based only on placement.

5

Create a drill

Important situations become spaced-repetition questions, allowing the player to retest reasoning outside a live match.

6

Measure recurring mistakes

The journal makes repeated decision patterns visible over several games without giving dynamic recommendations during play.

Competitive integrity

Explicit safety boundaries

The product is designed for passive capture and post-game reflection, consistent with Riot's stated support for tools that help players improve over time.

The application may

  • Record supported data belonging to the local player
  • Prefill context for a post-game review
  • Help the player identify recurring mistakes over time
  • Show static training objectives outside active gameplay
  • Create drills from completed reviews

The application will not

  • Tell a player when to roll, level, buy, sell or pivot
  • Adapt recommendations to the current live game state
  • Automate scouting or track opponent actions
  • Collect or display opponent boards or benches
  • Use prohibited augment or Legend performance data

Privacy by default

No account or central player database

Training records remain in the browser's local storage. The experimental desktop capture writes a separate local file. The public website contains no analytics scripts, tracking pixels or advertising.

Privacy Policy

Public distribution plan

Free core features

The planned Overwolf release will keep the core training workflow free. Monetization is intended to use non-intrusive Overwolf-supported advertising outside active gameplay, with a possible optional ad-free subscription later.

Riot reviewer path

Everything needed to evaluate the intended player experience

Reviewers can use the product without creating an account or installing software.

  1. Open the working browser prototype.
  2. Create a training objective on the Today screen.
  3. Add a decision and mark it for review.
  4. Complete the review and create a drill.
  5. Open the simulated Overwolf capture to inspect the planned passive data flow.
