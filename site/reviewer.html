Reviewer dossier

A direct path through the functional prototype, intended Overwolf flow, data handling and competitive-integrity boundaries.

Prepared August 3, 2026

Product summary

TFT Improvement System is a public, local-first post-game training application. It helps players document decisions, compare predictions with outcomes, identify recurring mistakes and create spaced-repetition drills.

What is testable now

  • a complete browser-based decision journal;
  • training objectives;
  • guided reviews;
  • spaced-repetition drills;
  • local backup and export;
  • a synthetic demonstration of the planned Overwolf capture flow.

Five-minute review path

  1. Open the browser prototype.
  2. On the Today screen, define a measurable objective.
  3. Select “Add a decision.” Complete the required context and action fields.
  4. Mark the decision for review and save it.
  5. Open Reviews, complete the analysis and create a drill.
  6. Open Drills to see the retest workflow.
  7. Run the simulated capture and watch local fields become stage snapshots.

Planned Overwolf behavior

The OW-Electron scaffold and mock provider are implemented. After Overwolf whitelisting, the live provider will request only allow-listed TFT Game Events Provider features. It will store supported local-player context in a separate local file and propose a post-game review after match end.

Why Riot approval is requested before live validation

Overwolf Developer Relations requires Riot approval before approving and whitelisting the TFT application idea. Without whitelisting, the developer cannot validate real GEP payloads. The synthetic flow therefore demonstrates the intended data path without claiming that live events have already been validated.

Current API status

The product does not currently call the Riot Games API and does not use Riot Sign On. The Production registration is requested because the public product serves TFT players and is planned to integrate with TFT through Overwolf. Any future official API or account-data feature will be registered before release.

Competitive-integrity boundaries

  • no live recommendations;
  • no direction to roll, level, buy, sell, pivot or reposition;
  • no automated scouting;
  • no opponent board or bench collection;
  • no augment or Legend performance statistics;
  • no automated gameplay inputs;
  • analysis only after the match or outside active gameplay.

Data model

Browser training data remains in browser local storage. Experimental desktop capture is stored in a separate local JSON file. The project operates no central player database and the public website contains no analytics scripts.
