Competitive integrity

Post-game analysis only.

TFT Improvement System is designed to improve player reasoning over time, not to solve the current match or bypass a skill test.

Last reviewed: August 3, 2026

Product classification

The product is a public training application intended for distribution through the Overwolf ecosystem. Its primary value is a structured learning workflow: decision capture, post-game review, conditional principles and spaced-repetition drills.

Brand integrity

The product has its own visual identity and does not imitate the Teamfight Tactics client or another Riot product. The public website and current prototype use no Riot or Teamfight Tactics logo, no official game-client interface and no copied promotional artwork. References to TFT identify the supported game and do not imply endorsement, sponsorship or official status. The required Riot disclaimer is displayed throughout the public website.

Live behavior

During active gameplay, the planned integration performs passive collection only. It does not display contextual recommendations, alerts that prescribe actions or an overlay that obstructs the game.

The application will not tell a player to roll, level, buy, sell, pivot, position, combine items or choose an augment based on the current game state.

Post-game behavior

After the match, the application may use supported local-player information to prefill factual context such as stage, health, gold, level, board state and final placement. The player remains responsible for identifying the decision, alternatives, prediction and learning principle.

Data allow-list

The initial live integration requests only the minimum Overwolf GEP features needed for the local-player workflow:

  • game and match state;
  • local player health, gold, XP, level and placement;
  • local board, bench, items and shop when supported;
  • round transitions, combat results and local-player damage when supported.

Prohibited and excluded uses

  • No opponent board or bench collection.
  • No automated scouting or opponent-action tracking.
  • No dynamic real-time information that dictates player decisions.
  • No automated gameplay, input simulation or queue interaction.
  • No augment or Legend win rates or average placements.
  • No attempt to bypass a short-term information-tracking skill test.
  • No account discrimination, queue dodging or player profiling.

Technical enforcement

The experimental capture engine uses an explicit field allow-list. Unknown and prohibited fields are rejected before being applied to a session. Rejected payload contents are redacted from diagnostics. Capture data is isolated from the learning database until event reliability has been validated with real matches.

Advertising

The prototype contains no advertising. The planned public release may use Overwolf-supported advertising only in desktop or post-game surfaces. Ads will not appear during active gameplay, cover game UI or influence training recommendations.

Policy-change process

New features involving game data, account access, remote storage, recommendations or monetization will be reviewed against current Riot and Overwolf policies before release. The Riot Developer Portal product metadata will be updated when required.

Reporting a concern

Potential compliance problems can be reported through the project's GitHub issue tracker. Reports should identify the relevant screen, feature and policy concern without including private account information.
