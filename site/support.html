Help and contact

Support

The public GitHub issue tracker is the primary support channel for the prototype.

Get help

Before opening an issue, review the README and existing GitHub issues.

Open a support issueView repository

Include in a bug report

  • the application version or commit;
  • browser, Windows and Overwolf versions where relevant;
  • steps required to reproduce the problem;
  • expected and actual behavior;
  • whether the problem occurred in browser, mock Electron or live Overwolf mode;
  • redacted diagnostics that do not contain private information.

Do not publish sensitive information

GitHub issues are public. Do not include Riot credentials, API keys, Overwolf credentials, authentication tokens, private account information, payment information or unredacted diagnostic payloads.

Delete browser data

  1. Open the application.
  2. Open Data and maintenance.
  3. Export a JSON backup if desired.
  4. Select Reset local data and confirm.

Browser records can also be removed by clearing site storage for the application domain.

Delete experimental desktop capture data

The OW-Electron prototype stores capture data in the application's Electron user-data directory under the file name overwolf-capture-v1.json. Close the application before deleting that file. Uninstalling the application may not remove every user-data file automatically, depending on the installer and operating-system settings.

Security vulnerabilities

Do not disclose an exploitable vulnerability with sensitive details in a public issue. Follow the instructions in the repository's Security Policy. If private reporting is not available, open a minimal issue requesting a private contact channel without publishing the exploit.

Compliance concerns

Report any feature that appears to provide a live competitive advantage, collect opponent data, use prohibited augment information or conflict with Riot or Overwolf policy. Such reports are treated as release-blocking until reviewed.

Response expectations

This is currently an independently maintained project. No guaranteed response time or service-level agreement is offered. Security, privacy and game-compliance issues receive priority over feature requests.
